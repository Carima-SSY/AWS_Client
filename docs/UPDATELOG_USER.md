# AWS Client v2 업데이트 안내

AWS Client는 3D 프린터 옆에서 실행되는 프로그램입니다. 장비의 상태, 카메라 화면, 출력 이력, 로그를 C-Hub 웹으로
보내고, 웹에서 보낸 파일과 명령을 장비에 전달합니다. 이 문서는 v2에서 달라진 점을 사용하는 입장에서 정리했습니다.

## 새 기능

### 더 많은 기종의 슬라이스 지원

- **대상 기종:** DM4K, IML, IML16K, IMDC, IMD, ZENESIS 등
- 이 기종들의 슬라이스는 v1에서 웹 슬라이스 목록에 나타나지 않았습니다.
- v2부터는 다음이 모두 됩니다.
  - 장비에 있는 슬라이스가 미리보기 이미지와 함께 웹 목록에 나타납니다.
  - 웹에서 보낸 슬라이스가 장비에 저장됩니다.
  - 웹에서 슬라이스를 지울 수 있습니다.
- X1 · DM400은 이전과 같이 동작합니다.

### 세부 모델 지원

- 다음 기종도 웹에 슬라이스 · 레시피 목록이 올라갑니다.
  - DM4K-H, DM4K-DS, DM4K-RS, DM4K-BD
  - X1 PRO, DM400 PRO
- 이전에는 이 기종들의 레시피 목록이 웹에 나타나지 않았습니다.
- DM400 PRO는 DM400과 같이 출력 대기열 기능을 쓸 수 있습니다.

### 저장 · 삭제 실패 알림

- 이전에는 웹에서 슬라이스나 레시피를 보내거나 지웠을 때 장비가 처리하지 못해도 웹에서는 알 수 없었습니다.
  웹에는 된 것처럼 보이는데 장비에는 없는 경우가 있었습니다.
- 이제 장비가 처리 결과를 웹으로 보내, 저장하거나 지우지 못하면 웹 화면에 알림이 뜹니다.
  알림이 뜨면 다시 보내 주세요.
- 이 알림은 웹 화면도 함께 업데이트되어야 나타납니다.

## 개선

### 장비와 웹의 목록이 저절로 다시 맞춰짐

- 이전에는 인터넷이 잠깐 끊기는 등의 이유로 웹에 목록을 보내지 못하면, 장비에서 슬라이스나 레시피가
  **다시 바뀔 때까지 웹이 예전 목록을 계속 보여 줬습니다.**
- 이제는 보내지 못하면 잠시 뒤 다시 보냅니다.
- 바뀐 것이 없어도 **5분마다 목록을 다시 보내**, 어떤 이유로 어긋나도 5분 안에 다시 맞춰집니다.

### 웹 반영이 더 빨라짐

- 이전에는 장비에 슬라이스가 많거나 로그 · 출력 이력을 올리는 중이면, 슬라이스 · 레시피 변경이 웹에 늦게 반영됐습니다.
- 이제는 바뀐 슬라이스만 다시 확인하고, 로그 · 출력 이력 올리기와 따로 처리해 더 빨리 반영됩니다.

### 다 저장된 슬라이스만 목록에 표시

- 레이어가 많은 슬라이스는 장비에 저장하는 데 몇 초가 걸립니다.
- 이전에는 저장하는 도중의 슬라이스가 목록에 보이거나, 저장 중에 지워져 일부만 남는 경우가 있었습니다.
- 이제는 **다 저장된 뒤에** 한 번에 목록에 나타납니다. 저장에 실패하면 기존 슬라이스는 그대로 남습니다.
- 같은 이름의 슬라이스를 다시 보내면 기존 슬라이스가 새 것으로 바뀝니다.

### 슬라이스 용량이 실제 크기로 표시

- 이전에는 일부 슬라이스의 용량이 실제보다 훨씬 작게 표시됐습니다.
- 이제 실제 용량이 표시됩니다.

### 덜 갖춰진 슬라이스를 지우지 않음

- 이전에는 미리보기 이미지 등이 빠진 슬라이스를 발견하면 **장비에서 바로 지웠습니다.**
  아직 복사가 끝나지 않은 슬라이스가 지워질 수도 있었습니다.
- 이제는 지우지 않고 **웹 목록에서만 보이지 않게** 합니다. 슬라이스가 다 갖춰지면 목록에 나타납니다.

## 오류 수정

### 장비 로그 · 출력 이력 업로드 누락

- 일부 로그와 출력 이력이 웹에 올라가지 않고 빠지는 경우가 있었습니다.
- 시험에서 이전 버전은 400건 중 2건만 올라갔고, v2는 **400건 모두** 빠짐없이 올라갔습니다.
- 인터넷이 끊겨 올리지 못한 로그 · 출력 이력도 이제는 버리지 않고, 연결되면 다시 올립니다.

### 큰 슬라이스를 받는 동안 다른 명령이 늦거나 빠짐

- 이전에는 웹에서 큰 슬라이스를 보내면, 장비가 받는 동안 웹에서 보낸 다른 명령이 늦게 처리되거나 빠질 수 있었습니다.
- 슬라이스를 받지 못한 경우, 그 뒤로 웹 명령이 장비에 전달되지 않을 수도 있었습니다.
- 이제는 슬라이스를 받는 일을 따로 처리해 다른 명령이 막히지 않습니다.
- 웹에서 보낸 업로드와 삭제는 보낸 순서대로 처리됩니다.

### 같은 오류 메시지 반복

- 실행 중 화면에 같은 오류 메시지가 반복해서 나타나는 경우가 있었습니다.
- 이제 이 오류가 나지 않습니다.
- 장비 전원이 갑자기 꺼져도 저장해 둔 정보가 지워지지 않습니다.

### X1 · DM400 레시피 삭제

- 웹에서 레시피를 삭제해도 장비에는 레시피가 그대로 남아 있었습니다.
- 이제 X1 · DM400(PRO 포함)에서는 장비의 레시피도 함께 삭제됩니다.
- 그 밖의 기종은 이전처럼 웹에서 장비 레시피를 삭제할 수 없습니다.

## 안정성

### 문제가 생겨도 장비가 느려지지 않음

- 이전에는 문제가 계속되면 프로그램이 쉬지 않고 같은 작업을 반복해 장비가 느려지고, 화면에 오류 메시지가 쏟아졌습니다.
- 이제는 잠시 쉬었다가 다시 시도하므로 장비에 부담을 주지 않습니다.
- 서버가 응답하지 않을 때 프로그램 일부가 멈춘 채로 있던 문제도 고쳤습니다. 이제는 잠시 기다린 뒤 다시 시도합니다.
- 오류가 나면 원인을 찾기 쉬운 정보가 함께 표시되어, 문의할 때 화면을 보내 주시면 더 빨리 확인할 수 있습니다.

## 업데이트 전에 확인하세요

1. **기종 확인:** 다음 기종은 바로 업데이트할 수 있습니다.
   - X1, X1 PRO, DM400, DM400 PRO
   - DM4K, DM4K-H, DM4K-DS, DM4K-RS, DM4K-BD
   - IML, IML16K, IMD, IMD-C, ZENESIS
   - 이 밖의 기종은 웹 슬라이스 · 레시피 목록이 비어 보일 수 있습니다. **업데이트하기 전에 개발 담당자에게 먼저 알려 주세요.**
2. **기존 설정 그대로 사용:** 지금 쓰는 설정 파일을 그대로 쓰면 됩니다.
3. **설치 방법:** v1과 같습니다. [INSTALL.md](INSTALL.md)를 참고하세요.
   설치 담당자는 로그와 출력 이력 폴더에 기본 파일이 있는지 확인해 주세요. 없으면 로그와 출력 이력이 웹에 올라가지 않습니다.

## 알아 두세요

- 웹에서 레시피를 삭제할 수 있는 기종은 X1 · DM400(PRO 포함)뿐입니다. 그 밖의 기종에서 삭제하면 "삭제하지 못함" 알림이 뜹니다.
- 장비가 꺼져 있거나 인터넷에 연결되지 않은 동안 웹에서 보낸 업로드 · 삭제 명령은 장비에 전달되지 않습니다. 연결된 뒤 다시 보내 주세요.
- 카메라 화면, 장비 상태 표시, 원격 출력 등 여기에 적지 않은 기능은 v1과 같습니다.
